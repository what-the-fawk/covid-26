# Исследование влияния области лёгких и технических артефактов на классификацию ренгенограмм

План:
1. Изучение [данных](https://www.kaggle.com/datasets/tawsifurrahman/covid19-radiography-database) и EDA
2. Изучение существующих подходов для решения поставленной задачи, первые прототипы ML-моделей
3. Исследование и реализация более сложных подходов к решению задачи
4. Планирование архитектуры итогового сервиса
5. Создание сервиса с имплементацией лучшего ML-решения
6. Эксперименты с DL-архитектурами, выбор и тюнинг лучшей/лучших архитектур
7. Финализация решения

Состав: Болоников Арсений, Балаян Степан, Миронов Сергей, Тодосиева Татьяна
